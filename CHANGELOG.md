# Changelog

All notable changes to Context Calibrated Beats are documented here.

## 1.0.1 — 2026-10-04

- Add the standard `context_calibrated_beats` Python package namespace.
- Preserve `API.py` and `CCB.py` as backward-compatible source entry points.
- Add `python -m context_calibrated_beats` support.
- Add English and Simplified Chinese README and instruction documents.
- Add Windows CI coverage and installed-package smoke tests.
- Add verified wheel and source-distribution builds.
- Add a trusted-publishing workflow for PyPI releases.
- Restrict the declared Python support range to the tested versions 3.10–3.12.

## 1.0.0 — 2026-10-03

- First public GitHub release.
- Provide CLI and Python function APIs for final beat-grid generation.
- Add persistent manual beat editing and `NO_BEAT` range management.
- Add local Beat This! inference caching and read-only inspection APIs.
- Add MIT licensing and third-party notices.
